Immutable stages; bounded handoffs

A stage is an independently addressable aggregate. Its execution tree ends at a terminal outcome; only a small, verified manifest crosses into a fresh successor tree. The active pointer is a rebuildable projection, never history.

Projection, not authority

active_stage_projection contains sorted active ids and an optional foreground id. Missing or corrupt projections rebuild from immutable indexed heads under lock. Ambiguity stops dispatch; it is never guessed.

  • Stage summary ≤16 KiB
  • History page ≤100 rows + cursor
  • Status, dashboard, review, sign-off, Retro open zero predecessor trees

Fail-closed authority

Every mutation rebinds exact run, repository/worktree, requirement/design, actor/session, and authority revision immediately before commit.

  • Stale authority: reject
  • Digest/path/bound failure: reject
  • R-0003 cleanup remains separate
  • Only exact registered + merged-tip-proven worktrees can be removed; every negative retains, never force

Conservative migration

Fingerprint and retain singleton source bytes first. Project only unambiguous facts. Anything ambiguous becomes an immutable legacy-unknown/v1 sentinel with an explicit reason—not pending, done, closed, or discarded.

  • Conserve requirements, tasks, decisions
  • Conserve evidence, commits, reviews, audit
  • Cut over adapter only after verified receipt
  • Rollback never collapses immutable history
