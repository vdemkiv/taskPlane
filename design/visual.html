Proof before authority; proof again before cleanup

R-0003 adds three canonical decisions while preserving the shipped ReviewKernel. Every uncertain branch stops locally and keeps evidence or worktree bytes intact.

1. Enforcement status

Exact workspace + session receipt and/or current screen activity
↓ canonical decision
live
Entry proceeds; closure rechecks proof.
unproven
Strict entry/closure refuses before mutation.
advisory
Only with attributable human acknowledgment; stamped everywhere.

2. Delivery isolation

Exact-workspace governed state?
No — no-op; Taskplane claims no authority.
Yes — classify with versioned registry.
  • Taskplane or helper: allow silently
  • Known competing driver: deny + audit
  • Unknown foreign: advise + audit; deny in strict isolation
  • Signed state root: report and exclude from write authority

3. Cleanup eligibility

Durable orchestrator merge receipt
↓ locked immediate revalidation
Exact managed registration + path/type/branch/tip + clean/released/non-variant + no retention/lock + tip ancestor of current primary
Any uncertainty → preserved; no force, no broader retry, no branch deletion
Remove exact linked worktree, verify absence, record removed or replay as already-clean

Post-Evaluate sequence

A. Evaluate passesTask is eligible to merge; variants remain retained.
B. Resolve primaryExact repository and primary ref; ambiguity stops.
C. Merge succeedsOrchestrator observes ordinary Git success.
D. Receipt commitsBranch/tip, primary tip, task, run, and path are fsync-durable.
E. Revalidate/removeOne no-force attempt; one idempotent maintenance replay after crash.

The cleanup arrow starts only after D. A crash before D preserves the tree; a changed fact at E preserves it; canonical requirements, design, plan, submissions, tests, review, audit, and sign-off records are never cleanup targets.
