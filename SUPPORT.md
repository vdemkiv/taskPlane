# taskplane support

For installation help, defects, or feature requests, open a public issue at:

https://github.com/vdemkiv/taskPlane/issues

For security-sensitive reports or matters that should not be public, contact:

Volodymyr Demkiv — vdemkiv@gmail.com

Include the taskplane version, host and host version, operating system, the
command or workflow being run, and a minimal reproduction. Remove source code,
credentials, personal data, and other confidential information before sharing
logs or screenshots.
