# Claude interactive recovery

Inspect the current run and exact native attempt before recovery. Preserve parent,
child, launch/handback/terminal observations, original or resumed cycle, loaded
runtime and relevant input identity. A launch failure, stop observation, terminal
notification and accepted result are separate facts.

Use supported controls for the observed condition. Cancellation does not prove
process exit; retain uncertain ownership and known command handles. Do not edit
the controller, manufacture hooks or replace a missing event with a label. New
runs resume a durable brief without startup accounting or context receipts.

Live interactive restart, actual permission outcomes and loaded hooks must be
observed on the final candidate. Local fixtures/script success cannot certify
them. Preserve historical attempts and report unavailable capability honestly.
