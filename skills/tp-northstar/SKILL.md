# Strategic review

Read the target and available product direction. Assess alignment, reversibility,
opportunity cost and coherence. State missing direction and recommend a concrete
next action. Keep the note proportionate to the decision.

This is advisory and grants no implementation authority. Attach it to matching
work when present; use [the shared flow](../tp-go/references/shared-flow.md) only
when the requested execution calls for a standalone Engineering result. Do not
invent an extra mandatory phase, lens quota, graph or dashboard gate.
